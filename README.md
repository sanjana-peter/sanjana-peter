## Featured Engineering

### 🚨 MCP Incident Triage Agent

**Production-oriented AI agent for investigating service incidents through typed MCP tools.**

The system connects a TypeScript agent to a custom MCP server over stdio, allowing the model to discover and invoke validated service-health and log-analysis tools before producing an evidence-based incident assessment.

```text
User / Incident
      │
      ▼
 AI Triage Agent
      │
      │ MCP
      ▼
 Custom MCP Server
      │
      ├── Service Health Tool
      ├── Log Analysis Tool
      └── Validated Tool Schemas
      │
      ▼
 Evidence-backed Incident Summary
```

**Engineering focus**

- MCP client/server architecture
- Structured tool discovery and invocation
- Schema validation with Zod
- LLM-driven tool selection
- Evidence-grounded incident analysis
- Automated testing with Vitest

`TypeScript` · `Groq` · `OpenAI Agents SDK` · `MCP` · `Zod` · `Vitest`

**[View Repository →](https://github.com/sanjanapeterlead/mcp-incident-triage-agent)**

**Modular CRM platform designed around lead capture, communication, scheduling, automation, and AI-assisted workflows.**

The platform is being built around a complete customer-acquisition workflow rather than isolated CRM screens, with integrations designed as replaceable modules so organizations can connect different lead sources and communication providers.

```text
Meta Lead Ads / Manual Leads
```
